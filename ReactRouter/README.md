🌐 React Routing Project

This project is a modern React application showcasing the use of React Router DOM for client-side routing, Tailwind CSS for sleek and responsive UI design, and essential React core concepts like components, props, hooks, and state management.

It also includes a feature to fetch and display a GitHub user profile by entering their username — demonstrating integration with a third-party API using fetch.
🔗 Live Demo

🌍 View Live on Netlify : https://react-routing-hitaansh.netlify.app/

🚀 Features

    ⚛️ Built using React functional components

    🧭 Client-side routing with react-router-dom

    🎨 Styled using Tailwind CSS

    🔍 GitHub profile fetcher — Enter a username to get public data

    🔁 React Hooks for managing state and side effects

    📱 Fully responsive design

    🌐 Hosted on Netlify

🛠️ Tech Stack

    React

    React Router DOM

    Tailwind CSS

    GitHub REST API

    Netlify (Hosting)


📦 Getting Started

    Clone the repository

    Run npm install

    Start the app with npm start

    Open http://localhost:3000/ in your browser
